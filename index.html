把资料交给 AI，整理成笔记、闪卡和模拟题

先设置 API key

这个工具用你自己的 Gemini key 读资料，可以免费申请：打开 aistudio.google.com/apikey，创建并复制 key，回到这里点「去设置」粘贴。

上传资料

    勾选的资料会在每次生成时一起发给 Google 的 Gemini。资料和 key 只保存在这台设备的浏览器里，这个网页本身不会把它们传到别处。免费版的 Gemini 可能用你发送的内容改进 Google 的产品，请不要上传带个人隐私的文件。

    AI 可能算错或漏写，考前请和课本、老师给的答案核对。

    设置

    key 只保存在这台设备的浏览器里，请求直接发给 Google。不要把 key 发给别人，也不要写进网页代码或上传到 GitHub。

    背景氛围会多耗一点电；页面不在前台时自动暂停，系统开了「减少动画」时不显示。

    开启后右下角有只小宠物，点它可以摸摸、也能拖动；关闭后完全不显示。

    备份包含笔记、闪卡、题目、错题本、对话和历史版本，不含 API key。

    填了之后，用同一个 API key 的设备会自动同步笔记、闪卡、题目、错题本和对话文字（资料文件和图片不同步）。内容在上传前已用 key 加密，云端只存密文。不填就完全不同步。
